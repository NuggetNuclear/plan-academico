# Wireframes del rediseño

Rama: `rediseño`. Base de diseño: [plan de UX](../plan-rediseno-ux.md).

`planner-wireframes-v2.html` es la dirección visual aprobada; `planner-wireframes.html` (v1) queda como referencia del flujo.

Este prototipo permite revisar Inicio, el registro de notas y la navegación móvil antes de cambiar la aplicación. Todos los datos son ejemplos. No se conecta al almacenamiento, importación ni sincronización del planner.

## Recorrido para revisar

1. Abrir Inicio y localizar la siguiente evaluación y la acción Registrar nota.
2. Entrar a Notas y registrar una evaluación del ramo seleccionado.
3. Probar una nota inválida, corregirla y guardar. Verificar la confirmación y Deshacer.
4. Cambiar a vista móvil y abrir Menú. Recorrer los grupos del lateral y volver al contexto de trabajo.
5. Comparar las mismas tareas en claro y oscuro.

Las secciones fuera de este alcance deben indicar que su contenido está pendiente de prototipar. Su presencia sirve para revisar la arquitectura; no demuestra que el rediseño completo esté implementado.

## Antes de implementar

La revisión solicitada por el usuario debe confirmar la jerarquía de Inicio, el recorrido de registro y el menú móvil. Después, la implementación seguirá las etapas y la matriz de conservación del plan de UX. Los cálculos académicos y los datos reales seguirán usando los módulos existentes.

El archivo `planner-wireframes.html` es el fragmento fuente para revisión, no una página de producción. Los resultados de las comprobaciones se documentan por separado; no implican certificación integral de accesibilidad.
